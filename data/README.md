# Data sources

A collection of data sources and evaluation datasets for climate extreme events.

### emdat_climate_events.ttl

A knowlegde graph which stores in RDF format information about climate extreme events gathered from the EM-DAT database in the time span between 2014 and 2026.
This can be used as a data source for RAG methods using RDF data as context knowledge.

## Benchmarks

A collection of benchmarks automatically generated by an LLM (`gpt-oss:120b-cloud`) prompted to output a question-answering dataset starting from some input context.

### benchmark_kg_only.csv

A benchmark generated using information deduced from the `emdat_climate_events.ttl` graph as context. The LLM was prompted to generate a question-answer pair given some structured context, initially derived from the EM-DAT database.

### benchmark_wwa_only.csv

A benchmark generated using information deduced from World Weather Attribution webpages. Each article was used as context in a textual format. The LLM was prompted to generate a question-answer pair given some natural language text.
